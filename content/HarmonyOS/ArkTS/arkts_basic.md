## 变量与常量

- `ArkTS`采用的是后置类型声明，通过冒号分割，格式是：`名字:类型`。
- 通过`let`关键词来声明变量，通过`const`关键词来声明常量。
- `ArkTS`支持自动类型推断，如果声明有初始化值，编译器会自动推断类型，开发者无需显式指定。

>[!important] 命名建议
>
> - 变量名通常是名词或名词短语，采用小驼峰命名，便于理解。
> - 常量命名，应该由全大写单词与下划线组成，单词间用下划线分割。常量命名要尽量表达完整的语义。

```ts
//变量
let hi : string = 'hello';
hi = '你好';

//常量
const pi : number = 3.14;

//自动类型判断
let world = '世界'

```

## 类型

ArkTS 的数据类型主要分为**基础类型**与**复杂类型**两大类。基础类型包括数字、字符串、布尔值等，用于处理简单数据；复杂类型如数组、对象、枚举等，用于组织结构化数据。

### 基本类型

### number

- ArkTS 支持整数与浮点数，不区分 int、float 等子类型，统一使用 `number` 表示。

| 数字子面量   | 类型         | 描述                                                 | 例子                                                                   |
| ------------ | ------------ | ---------------------------------------------------- | ---------------------------------------------------------------------- |
| 整数字面量   | 十进制整数   | 由数字序列组成。                                     | 0、117、-345                                                           |
|              | 十六进制整数 | 以0x（或0X）开头，包含数字（0-9）和字母a-f或A-F。    | 0x1123、0x00111、-0xF1A7                                               |
|              | 八进制整数   | 以0o（或0O）开头，只能包含数字（0-7）。例如：0o777。 | 0o777                                                                  |
|              | 二进制整数   | 以0b（或0B）开头，只能包含数字0和1。                 | 0b11、0b0011、-0b11                                                    |
| 浮点数字面量 | 常规小数     | -                                                    | 3.14、0.618、-2.5                                                      |
|              | 科学计数法   | 指数以“e”或“E”开头，后跟有符号（前缀为“+”或“-”）     | 2.5e3（表示 2.5 × 10³ = 2500）、1.23e-4（表示 1.23 × 10⁻⁴ = 0.000123） |

>[!warning] 精度注意
>number类型在表示大整数（即超过-9007199254740991~9007199254740991）时会造成精度丢失。
>
> 正数上限： ‭$2^{53} - 1$‬‭‬ （即 ‭$9,007,199,254,740,991$‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬）
> 负数下限： ‭$-(2^{53} - 1)$‬‭‬‭‬‭‬‭‬ （即 ‭$-9,007,199,254,740,991$‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬‭‬）

### boolean

- boolean类型由true和false两个逻辑值组成。

```ts
let isDone: boolean = false;

if (isDone) {
 console.info('Done!');
} else{
 console.info('Not Done!')
}
```

### string

- 可用前后两个单引号`'`和`"`括起来组成字符串。
- 可用反向单引号\`${}\``括起来传入指定的字符串。

```ts
let hi = 'Hello, world!\n';

let name: string = "HarmonyOS";
let msg: string = `欢迎使用${name}`;
```

### 复杂类型

#### array

- 数组类型，可用于存储同一类型的多个元素，支持范型定义。

>[!important] 数组类型表示
>
> ArkTS提供了两种数组类型的表示方式：`T[]`和`Array<T>`。建议所有数组类型均使用`T[]`表示，以提高代码可读性。

> [!attention] 数组遍历优先使用Array对象方法
> 
> 数组遍历，应该优先使用Array对象方法，如：forEach(), map(), every(), filter(), find(), findIndex(), reduce(), some()，而不是通过for i循环。

```ts
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ["张三", "李四"];
```
